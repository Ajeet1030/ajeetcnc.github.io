App me kya-kya milta hai

Jo kaam roz hota hai, wahi sab — simple tareeke se, bina extra jhanjhat ke.

LCD Total Hours Dashboard

Mahine ke total hours bade LCD numbers me sabse upar — saath me live clock, taaki time hamesha saamne rahe.

Colour-Tick Marking

Ek tap me haziri lagao — har status ka apna rang, calendar me turant pehchano.

PPresent AAbsent HHalf Day WWeekly Off LLeave

Auto + Manual Hours

In–Out time bharo, hours khud calculate ho jayenge: Out − In − Break. Ya seedha decimal me likh do — jaise 11.5 hours.

Overtime + Absent Hours

Standard hours se zyada kaam = overtime apne aap. Absent din ke hours bhi alag se gin liye jate hain — mahine ke aakhir me koi hisaab nahi bhoologe.

Employee Management

Poori team add karo, naam se search karo, kisi ki bhi attendance alag se dekho aur edit karo. Personal use ke liye sirf khud ko rakho — wo bhi chalega.

Monthly Calendar

Poora mahina ek nazar me — kis din present, kis din chhutti, sab rang ke saath calendar par saaf dikhta hai.

Monthly Report + Salary Estimate

Mahine ki poori report — total hours, overtime, absent — aur usi hisaab se salary ka andaza bhi ready milta hai.

Excel / CSV / PDF Export

Report ko Excel, CSV ya PDF me nikalo — office me bhejna ho ya record rakhna ho, ek tap me file taiyaar.

Backup + Restore

Saara data backup file me save karo. Phone badlo ya app dobara lagao — Restore se pura record wapas aa jayega.

Login system — Admin aur Employee

Har company ka data alag aur safe. Admin apni company khud banata hai, employee sirf apna record dekhta hai.

Admin

Company ka malik

  • Apni company khud create karta hai, apna password khud set karta hai
  • Apni company ka sab kuch dekh aur edit kar sakta hai — employees, attendance, reports
  • Dusri company ka data use dikhta hi nahi
  • Employees ko view password deta hai
Employee

Sirf apna record

  • Admin ke diye hue view password se login karta hai
  • Sirf apni attendance, hours aur report dekh sakta hai
  • View-only — kuch edit nahi kar sakta
  • Kisi aur employee ka data nahi dikhta

Aksar puche jaane wale sawaal

Mera data kahan save hota hai?

Saara data aapke apne device me save hota hai — attendance, employees, reports sab phone par hi rehta hai, aur ek copy device storage me bhi apne aap banti rehti hai. Iske alawa Backup feature se poora data ek file me download karke kahin bhi safe rakh sakte ho, aur zaroorat padne par Restore se wapas la sakte ho.

Admin aur Employee me kya farak hai?

Admin apni company khud banata hai, apna password set karta hai aur apni company ka sab data dekh-edit kar sakta hai. Employee ko Admin ek view password deta hai — employee login karke sirf apni attendance aur hours dekh sakta hai, edit kuch nahi kar sakta, aur kisi aur ka data use dikhta hi nahi.

Kya ye app free hai?

Haan, bilkul free hai. APK download karo, install karo aur use karo — koi charge nahi, koi subscription nahi.

Kis phone par chalega?

Kisi bhi Android phone par chalega jisme Android 6.0 ya usse upar ka version ho. App sirf 17 KB ka hai — purane phone par bhi aaram se chalega aur jagah bhi nahi gherega.
