CNC G/M code library

Core controller codes, plain-English uses, and quick shop-floor reference.

G/M CODES

Find a code or use

common Fanuc / Haas patterns
⌕
Motion & setup
G00Rapid positioningMoves the tool quickly without cutting. Use only where the path is clear.
G01Linear interpolationFeeds the tool in a straight line at the programmed feed rate.
G02Clockwise arcCuts a clockwise circular move in the active plane.
G03Counter-clockwise arcCuts a counter-clockwise circular move in the active plane.
G04DwellPauses for a programmed time, commonly used for boring or tapping.
G17 / G18 / G19Plane selectionSelects XY, XZ, or YZ plane for arcs and canned cycles.
G20 / G21UnitsSets inch or metric input. Put it near the start of every program.
G90 / G91Positioning modeG90 uses absolute coordinates; G91 uses incremental moves.
G94 / G95Feed modeFeed per minute for milling; feed per revolution for turning.
Offsets & compensation
G40Cancel cutter compensationTurns off G41/G42 cutter radius compensation.
G41 / G42Cutter compensationOffsets the tool left or right of the programmed contour using D offset.
G43 H##Tool length compensationApplies the tool length offset from the H register, normally with Z.
G49Cancel tool lengthTurns off the active G43 tool length compensation.
G54–G59Work coordinate systemsSelects the active work offset for the part setup.
G28Reference returnReturns an axis to machine reference. Use a safe intermediate position.
G50Spindle limit / scalingOn many lathes, limits maximum RPM during constant surface speed.
Mill canned cycles
G80Cancel canned cycleAlways cancel drilling cycles before rapid or contour moves.
G81Simple drillingDrills to depth and retracts to the programmed retract plane.
G82Spot drill / counterboreDrilling cycle with a dwell at the bottom of the hole.
G83Peck drillingDeep-hole cycle that pecks to break chips and clear coolant.
G84TappingRigid or synchronized tapping cycle, depending on the control.
Lathe cycles
G96 / G97CSS / fixed RPMG96 enables constant surface speed; G97 returns to fixed RPM.
G70Finishing cycleRuns a finishing pass over a previously defined roughing profile.
G71OD / ID roughingRough-turns a profile using repeated depth-of-cut passes.
G72Facing roughingRoughs a face profile with repeated cuts across the part.
G76Threading cycleMulti-pass threading cycle; exact syntax varies by control.
Machine functions
M00 / M01Program stopM00 always stops; M01 stops only when optional stop is enabled.
M03 / M04Spindle directionStarts spindle clockwise or counter-clockwise at the programmed S speed.
M05Spindle stopStops spindle rotation before tool change or program end.
M06Tool changeChanges to the tool selected by the T command on supported machines.
M08 / M09Coolant on / offTurns flood or programmed coolant on and off.
M30End and resetEnds the program and commonly resets the control to the start.
Words inside a block
O####Program numberIdentifies the CNC program stored in the control.
N####Sequence numberLabels a block for search, restart, or subprogram navigation.
S####Spindle speedSets RPM in fixed-speed mode or surface speed in CSS mode.
F####Feed rateSets cutting feed; units depend on G94 or G95.
T##Tool selectSelects the tool and often the offset station before M06.
X / Y / ZAxis positionsDefines linear endpoint coordinates in the active work system.
I / J / KArc center vectorsDefines the arc center offset from the start point.
RRadius / retract planeSets an arc radius or the retract plane in a canned cycle.
Controller note: G/M-code behavior and exact cycle format can differ by Fanuc, Haas, Siemens, Mazak, and machine builder. Simulate and dry-run every new program before cutting.
